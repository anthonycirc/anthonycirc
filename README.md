## 🧭 Philosophy first

Before tools, **principles** :

- **SOLID** — maintainable, decoupled object design
- **DDD** — Domain-Driven Design, bounded contexts, aggregates, domain events
- **TDD** — tests drive the design, not the other way around
- **Hexagonal Architecture** — ports & adapters, infrastructure stays at the edge
- **DRY / YAGNI / KISS** — no over-engineering, no duplication
